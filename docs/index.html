Use it outside Cursor

  • This github.io page is public. Open it in any browser. You do not need Cursor for it.
  • To sit questions, run the app on your computer, then open http://localhost:3000 in Safari or Chrome.
  • Cursor is only an editor. Terminal + a normal browser is enough to study.
  • GitHub Pages cannot run the player — it needs Node and SQLite on disk.
  • Mac: if Terminal says pnpm: command not found, install Node first. Cursor’s Node is not on this PATH. Do not clone the repo a second time inside itself.
  • Every card is a retrieve. Confidence 1–5 before the key is shown.
  • Factory volume is unverified AI until a human or official paper says otherwise.
xcode-select --install
brew install node
corepack enable
corepack prepare pnpm@10.33.3 --activate

git clone https://github.com/bobshenruililin/MCAT-GAMSAT.git
cd MCAT-GAMSAT
pnpm install
FACTORY_TARGET=423500 PATTERN_TARGET=12000 pnpm bootstrap
pnpm sit

Leave that terminal open. In Safari or Chrome go to http://localhost:3000 and hit Continue. Cap bootstrap with FACTORY_TARGET if the SQLite file would be too large.
